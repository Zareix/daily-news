## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🪤 Un fichier AGENTS.md piégé détourne les agents de code IA

Des chercheurs ont trouvé dans le dossier Téléchargements d'un client un fichier d'instructions `AGENTS.md` malveillant, destiné à faire installer un paquet npm compromis par l'agent de code IA qui passerait par là. L'attaque exploite la lecture automatique des fichiers de contexte et de consignes présents dans le répertoire courant : tout fichier déposé dans un dossier de travail peut devenir une instruction.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/10/malicious-file-in-downloads-folder.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-coding-agents-hijacked-using-agentsmd-file-in-downloads-folder/)

### 🔑 Tailscale SSH : des failles non corrigées mènent au root

Un chercheur a publié des failles non patchées dans Tailscale SSH permettant, depuis un seul appareil compromis du tailnet, d'obtenir un accès root sur les autres serveurs qu'il peut atteindre. Le risque est structurel : la confiance accordée au réseau maillé devient un chemin d'escalade latérale.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/unpatched-tailscale-ssh-flaws-could-let.html)

### 💥 Le décodeur Brotli touché par une corruption mémoire, au-delà de Node.js

La faille de corruption mémoire à l'origine d'une exécution de code à distance dans Node.js concerne en réalité tous les programmes qui décompressent du Brotli : Bun, .NET de Microsoft, les paquets Python `Brotli` et `brotlicffi`, Envoy, entre autres. La surface d'exposition dépasse donc largement l'écosystème JavaScript d'origine.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/brotli-decoder-flaw-behind-nodejs-rce.html)

### 🧬 BlackX : un bootkit UEFI contourne Secure Boot

Un nouveau bootkit UEFI nommé BlackX, déployé dans une campagne d'espionnage début 2026, exploite l'ancienne faille « Baton Drop » pour contourner Secure Boot et charger un pilote malveillant. Le cas rappelle qu'un firmware non mis à jour reste un vecteur de persistance invisible pour l'antivirus.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/blackx-uefi-bootkit-exploits-baton-drop-flaw-to-bypass-secure-boot/)

### 🧨 PHP2Shell et la fuite de clé maîtresse LiteLLM

Les tentatives d'exploitation de PHP2Shell se poursuivent, avec un balayage mondial suspecté d'origine nord-coréenne, tandis que Palo Alto Networks est revenu sur son évaluation initiale du compromis visant une agence gouvernementale européenne. Séparément, LiteLLM a révélé qu'une clé maîtresse d'Agent Platform publiée par erreur sur un dépôt GitHub public en mai 2026 avait permis de voler des jetons GitHub et de publier une version malveillante du logiciel.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/10/php2shell-exploitation-hits-government.html) · [The Hacker News](https://thehackernews.com/2026/10/leaked-litellm-master-key-let-attackers.html)

## 🚨 À appliquer sans attendre

1. **Agents de code IA** : interdire la lecture automatique des fichiers `AGENTS.md`, `CLAUDE.md` et consorts présents dans les dossiers de téléchargement ou de travail non maîtrisés, et vérifier le contenu de ces fichiers avant de lancer un agent dans un répertoire récupéré d'ailleurs. Auditer les paquets npm installés récemment par un agent.
2. **Tailscale SSH** : sans correctif disponible, restreindre les ACL du tailnet au strict nécessaire, désactiver Tailscale SSH sur les serveurs sensibles et considérer tout appareil du réseau comme un point d'entrée potentiel vers le root.
3. **Brotli** : mettre à jour Node.js, Bun, .NET, Envoy et les paquets Python `Brotli` / `brotlicffi` dès que les versions corrigées sortent — la faille permet une exécution de code à distance là où des données Brotli non fiables sont décompressées.
4. **Secure Boot / UEFI** : appliquer les mises à jour de firmware et vérifier que « Baton Drop » est bien corrigé côté OEM ; le bootkit BlackX survit aux réinstallations de l'OS.
5. **Secrets** : rotation des clés maîtresses LiteLLM et des jetons GitHub exposés, et recherche de secrets dans l'historique des dépôts publics.
