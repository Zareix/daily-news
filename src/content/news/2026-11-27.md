## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🔑 1Password : données clients volées via un compte GitHub salarié

1Password a révélé qu'un compte GitHub d'employé compromis a servi à déployer du code malveillant dans ses services backend, donnant accès à des informations clients. Le gestionnaire de mots de passe affirme que les coffres chiffrés et les clés maîtresses n'ont pas été exposés.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/1password-hacked-customer-data-and.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/1password-customer-data-stolen-after-employee-github-account-breach/)

### 🐛 Cacti : un zéro-day non corrigé donne une RCE en quatre requêtes

Une vulnérabilité non patchée dans Cacti, outil open source de supervision réseau, permet à un attaquant disposant d'un accès invité d'obtenir une exécution de code à distance en quatre requêtes HTTP. Un PoC circule déjà.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/unpatched-cacti-zero-day-enables-rce-in.html)

### 🧩 Drupal : faille « hautement critique » exploitée activement

Drupal alerte sur une vulnérabilité de prise de contrôle de site affectant le cœur de Drupal (CVE-2026-136716), déjà exploitée dans la nature. Les sites non mis à jour sont exposés à une compromission complète.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/drupal-warns-of-new-highly-critical.html)

### 🇰🇵 PolinRider : 7 600 dépôts GitHub empoisonnés

La campagne liée à la Corée du Nord plante un loader Python dans des dépôts GitHub pour diffuser des malwares, avec des traces remontant à février dernier. Les développeurs qui clonent puis exécutent ces projets sont les cibles directes.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/north-korea-linked-polinrider-poisons.html)

### 🇨🇭 Des attaques autonomes pilotées par IA contre des infrastructures critiques

L'agence suisse de cybersécurité confirme que des attaquants utilisant des agents IA ont pénétré les systèmes d'organisations helvétiques dans quatre des cinq attaques confirmées — une première dans le pays. L'Italie publie un avertissement similaire, ciblant le secteur des infrastructures critiques.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/switzerland-confirms-ai-assisted.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/italy-and-switzerland-warn-of-autonomous-ai-driven-cyberattacks/)

### 🧱 Palo Alto : Fragnesia exploité sur PAN-OS

Palo Alto Networks confirme l'exploitation de la faille Fragnesia, chaînée avec PHP2Shell, contre des équipements dont l'interface de management est exposée sur internet. La parade immédiate reste de restreindre l'accès à cette interface.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/palo-alto-networks-warns-of-fragnesia-flaw-exploited-in-pan-os-attacks/)

## 🚨 À appliquer sans attendre

1. **Drupal** : mettre à jour le cœur dès que le correctif est disponible — l'exploitation est déjà en cours dans la nature (CVE-2026-136716).
2. **Cacti** : pas de patch ; supprimer ou restreindre l'accès invité et fermer l'instance au réseau tant qu'un correctif n'est pas publié.
3. **Palo Alto PAN-OS** : ne jamais laisser l'interface de management exposée sur internet ; appliquer les correctifs Fragnesia et PHP2Shell.
4. **1Password** : vérifier les notifications de sécurité du compte, renouveler les sessions actives et surveiller les accès inhabituels.
5. **Dépôts GitHub** : ne pas exécuter de projet cloné sans lecture du code (loader Python de PolinRider), et auditer les extensions Chrome — Remus et SYS01 passent par des extensions malveillantes ciblant Gmail et Outlook.
