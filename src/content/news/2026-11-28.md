## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🐛 Cacti : zero-day non corrigé avec PoC public, RCE en quatre requêtes

Une vulnérabilité zero-day dans la plateforme open source de supervision réseau Cacti est publiquement détaillée, avec un exploit fonctionnel permettant à un attaquant non authentifié d'exécuter du code via un simple accès invité. Aucun correctif n'est disponible à ce jour.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/unpatched-cacti-zero-day-with-public-poc-gives-remote-code-execution/) · [The Hacker News](https://thehackernews.com/2026/11/unpatched-cacti-zero-day-enables-rce-in.html)

### 🔑 Gestionnaires de mots de passe : 1Password piraté, pCloud Pass confirme

1Password a révélé un incident survenu via un compte GitHub compromis, avec vol de données clients et de code source. pCloud a de son côté confirmé une attaque contre pCloud Pass, des utilisateurs ayant vu des appareils inconnus se connecter à leur compte malgré la 2FA.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/1password-hacked-customer-data-and.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/pcloud-confirms-password-manager-hack-after-suspicious-login-alerts/)

### 🐍 PolinRider : plus de 7 600 dépôts GitHub empoisonnés

La campagne attribuée à la Corée du Nord a compromis des milliers de dépôts GitHub, y plantant dans certains cas un loader Python capable de livrer une charge de second niveau. Les projets qui installent leurs dépendances depuis des dépôts inconnus sont directement exposés.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/north-korea-linked-polinrider-poisons.html)

### 🛡️ Drupal : deuxième faille critique déjà exploitée

L'équipe sécurité de Drupal alerte sur une seconde vulnérabilité critique permettant de contourner l'authentification et de prendre le contrôle de sites non patchés, activement exploitée. Un correctif est publié : les mises à jour ne peuvent pas attendre.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/drupal-warns-of-new-access-bypass-flaw-exploited-in-attacks/)

### 🇨🇭 La Suisse confirme des intrusions assistées par IA dans des infrastructures critiques

L'agence nationale de cybersécurité suisse rapporte que des attaquants utilisant des agents IA ont pénétré des systèmes d'organisations helvétiques dans quatre des cinq attaques confirmées. Une première dans le pays, qui illustre la montée en charge de l'automatisation offensive.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/switzerland-confirms-ai-assisted.html)

## 🚨 À appliquer sans attendre

1. **Cacti** : aucune correction disponible — restreindre immédiatement l'accès à l'interface web (pare-feu, VPN), désactiver l'accès invité et surveiller les journaux HTTP en attendant un patch.
2. **Drupal** : appliquer sans délai la mise à jour de sécurité (contournement d'authentification exploité) et vérifier les comptes administrateurs créés récemment.
3. **Gestionnaires de mots de passe** : changer le mot de passe maître de 1Password et de pCloud Pass, révoquer les sessions et appareils inconnus, vérifier les alertes de connexion.
4. **Développeurs** : auditer les dépôts GitHub et les dépendances Python installées récemment (campagne PolinRider), et n'installer que depuis des sources signées.
5. **Windows Server 2025** : déployer le hotpatch hors bande de Microsoft qui corrige les crashs provoqués par KB5131077.
