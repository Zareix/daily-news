### 🔑 Claude Code laisse fuiter des secrets dans 1 122 fichiers GitHub

Les mots de passe et clés d'API que des développeurs ont tapés dans des commandes approuvées via l'option « Yes, and don't ask again » de Claude Code se retrouvent dans des dépôts publics, où n'importe qui peut les lire. Le fichier de préférences conserve les commandes en clair ; l'étude recense 1 122 copies publiques.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html) · [HN (346 pts)](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)

La banque coopérative française a été visée par une cyberattaque ayant permis des transactions frauduleuses pouvant atteindre 133 millions de dollars, via un prestataire de services. Arkéa a réagi en suspendant certains systèmes ; l'enquête porte sur le vecteur d'entrée chez le fournisseur.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-pull-off-133-million-french-bank-heist-via-service-provider/)

### 🛡️ SonicWall : contournement MFA SSL-VPN déjà exploité

SonicWall publie des correctifs pour sept vulnérabilités de SonicOS, dont un contournement d'authentification SSL-VPN exploité dans la nature permettant de passer outre le MFA. Les pare-feux exposés sur Internet doivent être mis à jour et leurs journaux d'accès distants examinés.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/sonicwall-warns-of-new-ssl-vpn-mfa-bypass-flaw-exploited-in-attacks/)

### 🗄️ QNAP : la chaîne Plex2Shell exploite les NAS

QNAP appelle à mettre à jour Plex Media Server depuis l'App Center, des attaquants exploitant une chaîne de vulnérabilités baptisée Plex2Shell pour pénétrer les NAS exposés. Les modèles accessibles depuis Internet sont la cible prioritaire.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/qnap-says-hackers-breaching-nas-devices-in-plex2shell-attacks/)

### 🎭 Faux outils de sécurité sur GitHub : backdoors et infostealers

Des projets estampillés « sécurité » sur GitHub diffusent en réalité une backdoor et un voleur d'informations, ciblant explicitement les professionnels du secteur. Les paquets incriminés imitent des outils connus et s'installent via des commandes copiées telles quelles.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/fake-security-tools-on-github-push-backdoors-and-infostealers/)

### 🪙 Chainalysis : identifiants de tous les clients exposés

La société d'analyse blockchain reconnaît qu'une attaque « agentique » contre ses systèmes a exposé noms, identifiants, hachages de mots de passe et jetons actifs de l'ensemble de ses clients. Plusieurs services clés ont été arrêtés le temps de l'investigation.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/chainalysis-breach-exposes-all-users.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/chainalysis-says-breach-exposed-credentials-for-all-customers/)

## 🚨 À appliquer sans attendre

1. **SonicWall SonicOS** : appliquer les correctifs des sept failles, en priorité le contournement MFA SSL-VPN exploité ; couper l'accès SSL-VPN depuis Internet en attendant si le patch ne peut pas être déployé immédiatement.
2. **QNAP / Plex** : mettre à jour Plex Media Server via l'App Center et vérifier les comptes et tâches planifiées sur les NAS exposés.
3. **OpenSSH** : la faille « SSHole », permettant de se connecter à des comptes sans mot de passe, est exploitée quelques heures après sa divulgation ; mettre à jour OpenSSH et désactiver l'authentification par mot de passe vide.
4. **Secrets dans les dépôts** : purger le fichier de préférences de Claude Code (option « don't ask again »), le mettre en `.gitignore`, et révoquer toute clé ayant transité par une commande shell enregistrée.
5. **Crédit Mutuel Arkéa** : si vous êtes client, surveiller les opérations récentes et privilégier la validation des virements dans l'application plutôt que par téléphone.
