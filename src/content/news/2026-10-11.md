## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🔗 GitHub Actions : des workflows voleurs de credentials plantés dans des dizaines de milliers de dépôts

Une campagne en cours de vol de credentials a compromis deux comptes de mainteneurs open source de premier plan afin de diffuser des workflows GitHub Actions malveillants, disséminés dans des dizaines de milliers de dépôts. Les mainteneurs de projets CI/CD sont invités à auditer leurs workflows et leurs secrets.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/credential-stealing-github-actions.html)

### 📱 P7 DarkSword : un kit d'exploit iOS enrichi du vol de portefeuilles crypto

Des chercheurs détaillent P7 DarkSword, variante inédite du kit d'exploit iOS DarkSword, qui ajoute le vol des données de portefeuilles de cryptomonnaies et l'exécution de commandes à distance sur les appareils visés.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/p7-darksword-ios-exploit-kit-adds.html)

### 🖥️ AnyDesk Linux : un exploit public pour une faille pre-auth donnant accès root

Un exploit fonctionnel a été publié pour une faille d'exécution de code à distance sans authentification dans AnyDesk sous Linux : l'attaquant obtient les droits root avant toute authentification. Toute instance AnyDesk Linux exposée doit être mise à jour.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/researchers-publish-working-exploit-for.html)

### 🪤 « Adception » : un faux installeur Claude poussé via les annonces Google

Des chercheurs de Push Security ont repéré une campagne d'annonces Google pointant vers une redirection légitime de Bing (`bing.com/ck/a`) puis vers un site WordPress compromis, qui redirige vers une page d'installation imitant Claude pour macOS. Le bouton « copier » place dans le presse-papier une commande malveillante (qui télécharge un fichier depuis un serveur contrôlé et l'exécute dans `zsh`) au lieu de la commande officielle `curl -fsSL https://claude.ai/install.sh`.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-abuse-google-ads-bing-redirects-to-push-claude-clickfix-attacks/)

## 🚨 À appliquer sans attendre

1. **Toujours à patcher** : Citrix NetScaler ADC / Gateway (CVE-2026-107406, RCE, instances configurées en SAML) et SonicWall SMA1000 (CVE-2026-102255, exploits observés) — versions corrigées 14.1-73.46 / 13.1-64.29 et suivantes.
2. **Dépôts GitHub** : auditer les workflows GitHub Actions et vérifier l'intégrité des fichiers de CI (campagne de vol de credentials en cours) ; révoquer tout secret susceptible d'avoir fuité.
3. **IA** : n'installer Claude que depuis `claude.ai` — la campagne « Adception » détourne les annonces de recherche vers un faux installeur macOS dont le bouton « copier » injecte une commande malveillante.
4. **AnyDesk Linux** : mettre à jour toute instance exposée, un exploit public donne un accès root avant authentification.
