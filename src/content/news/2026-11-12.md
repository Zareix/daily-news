## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🌐 Apache : faille RCE critique dans mod_http2 (CVE-2026-119618)

Une vulnérabilité critique du module HTTP/2 du serveur Apache permet à un attaquant non authentifié d'exécuter du code à distance. Elle touche les versions 2.4.55 à 2.4.70 et est corrigée en 2.4.71 ; le sujet est en tête de Hacker News avec 146 points.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html) · [Wiz](https://www.wiz.io/blog/cve-2026-119618-rce-apache-http-server-vulnerability)

### 🐙 4 837 comptes GitHub détournés pour voler des secrets CI

Depuis mardi, un attaquant utilise des identifiants volés sur 4 837 comptes GitHub pour planter un voleur de secrets dans les dépôts auxquels ils ont accès : plus de 1 806 dépôts seraient concernés, selon Aikido Security. Les secrets de CI/CD exposés permettent ensuite de pivoter vers les registres, clouds et environnements de production.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html)

### 🖥️ ScreenConnect : des clients pirates déployés chez des MSP

ConnectWise a désactivé par précaution cinq extensions tierces dans les environnements partenaires.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/active-screenconnect-attacks-breach-msps-impact-dozens-of-organizations/) · [The Hacker News](https://thehackernews.com/2026/11/screenconnect-attacks-target-at-least.html)

## 🚨 À appliquer sans attendre

1. **Apache HTTP Server** : passer en 2.4.71 immédiatement sur tout serveur exposé avec `mod_http2` activé (CVE-2026-119618, RCE non authentifiée) ; en attendant, désactiver HTTP/2 si la mise à jour ne peut être planifiée.
2. **GitHub / CI** : auditer les comptes disposant d'un accès en écriture aux dépôts, révoquer les tokens inutilisés, vérifier l'absence de workflows ajoutés sans revue et renouveler les secrets de CI/CD ; épingler les actions tierces sur un SHA.
3. **ScreenConnect / ConnectWise** : recenser les clients d'accès distant installés, bloquer les binaires non signés ou non reconnus, vérifier les extensions tierces désactivées par l'éditeur.
4. **Windows / Outlook** : déployer les cumulatifs de novembre 2026 en priorité sur les postes exposés à Internet et les serveurs concernés par la fuite de hashes NTLMv2.
5. **Zoom Workplace (Windows)** : appliquer la mise à jour corrigeant l'élévation de privilèges critique.
6. **N-able N-central** : installer les hotfixes des zero-days divulgués publiquement le week-end dernier.
