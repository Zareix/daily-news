## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🇩🇰 Danemark : le registre civil CPR fuit les données de 8,8 millions de personnes

Le registre central de la population danoise (CPR) a subi une fuite exposant les données (noms, adresses, dates de naissance, numéros CPR) d'environ 8,8 millions de personnes, soit près de 80 % des 11 millions d'enregistrements. Des attaquants ont exploité l'accès légitime d'une société privée et du force brute pour énumérer des numéros valides ; l'incident remonte à septembre mais la taille de l'impact n'a été établie que le week-end dernier.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/denmark-population-registry-data-breach-affects-88-million-people/) · [The Hacker News](https://thehackernews.com/2026/10/denmark-says-attackers-accessed-cpr.html)

### 🌐 Rejetto HFS : CVE-2026-61500 (RCE critique) activement scannée

Des honeypots détectent des scans ciblant une faille de signature de cookie de session de Rejetto HFS (CVE-2026-61500) : la clé est dérivée d'un générateur non cryptographique et divulguée aux clients non authentifiés, ce qui permet de forger un cookie d'administrateur et d'exécuter du code à distance via la fonction server_code. La faille, publiée début septembre, est corrigée depuis la version 3.2.1.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/rejetto-hfs-servers-now-actively-scanned-for-critical-rce-flaw/) · [The Hacker News](https://thehackernews.com/2026/10/attackers-target-rejetto-hfs-flaw-that.html)

### 💻 Dell System Update : CVE-2026-86360 permet l'obtention des privilèges root

Dell alerte sur une vulnérabilité critique (CVE-2026-86360) de l'outil en ligne de commande Dell System Update (DSU), qui permet à un attaquant non authentifié d'exploiter un path traversal pour exécuter du code arbitraire avec les privilèges root. Quatre autres failles (dont deux d'exécution de code à distance) ont été corrigées en parallèle.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-dell-system-update-flaw-lets-hackers-gain-root-privileges/)

### 📧 Microsoft Exchange : une faille permet à un utilisateur authentifié de lire les boîtes des autres

Une vulnérabilité d'Exchange permet à un attaquant authentifié de lire les boîtes aux lettres d'autres utilisateurs du serveur, un vecteur d'escalade interne à ne pas négliger en environnement hybride.

## 🚨 À appliquer sans attendre

1. **Rejetto HFS — CVE-2026-61500 (RCE, signée et activement scannée)** : mettre à jour vers la version 3.2.1 au minimum, idéalement 3.3.4, toute instance exposée sur Internet. Le PoC public (Horizon3, 30 septembre) rend l'exploitation triviale — si la mise à jour n'est pas immédiate, retirer le service du réseau public.
2. **Dell System Update — CVE-2026-86360 (exécution de code avec privilèges root)** : mettre à jour Dell System Update vers la version 2.3.0.0 ou supérieure. Prioritaire sur les serveurs PowerEdge exposés ou multi-utilisateurs.
3. **Microsoft Exchange** : appliquer le correctif de la faille de lecture de boîtes aux lettres ; vérifier les accès internes et les comptes de service, un attaquant authentifié pouvant lire les courriels d'autres utilisateurs.
4. **ClickFix** : rappeler aux utilisateurs de ne jamais coller dans « Exécuter » (Win+R) ou une console de commandes une instruction trouvée sur une page web ; vider le cache du navigateur fait partie des réflexes de nettoyage.
5. **Rappel — Citrix NetScaler CVE-2026-88779** (couvert hier) : toujours exploité en attaques ciblées, les appliances configurées en SAML doivent être repatchées (14.1-73.41 / 13.1-64.28), même si elles ont déjà reçu les correctifs CVE-2026-88771 à 88778.
