## 🇫🇷 FRANCE

### 🗳️ Budget 2027 : la dernière bataille de Sébastien Lecornu

## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🇺🇸 Cisco Catalyst SD-WAN Manager : zero-day exploité, accès admin sans authentification

Cisco a publié des correctifs pour CVE-2026-76504, une faille de gestion de l'encodage d'URI qui permet de contourner l'authentification d'un point d'API et d'agir en administrateur, sans aucun identifiant. L'exploitation est active depuis septembre, tous les déploiements sont concernés et il n'existe pas de contournement : les indicateurs publiés pointent l'usage de `%6a` pour le caractère « j » et des entrées `j_security_check` dans les journaux.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisco-warns-of-new-sd-wan-authentication-bypass-zero-day-exploited-in-attacks/) · [The Hacker News](https://thehackernews.com/2026/09/cisco-warns-of-attackers-exploiting.html)

### 🐚 Citrix NetScaler : CVE-2026-88772 exploitée pour poser des web shells et obtenir root

La vulnérabilité de command injection pré-authentification des NetScaler ADC et Gateway (CVSS 9.5) est exploitée en Europe et en Amérique du Nord pour déployer des web shells et des outils de tunnellisation, obtenir un accès root et voler des identifiants. Les chercheurs ont documenté la création d'un superutilisateur et un mappage des web shells sur des URL imitant des fichiers CSS.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/09/citrix-netscaler-cve-2026-88772-exploit.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-citrix-netscaler-zero-day-to-deploy-web-shells/)

### 📡 MikroTik RouterOS : un RCE pré-authentifié critique signalé par la CISA

CVE-2026-84411 est un underflow d'entier dans le traitement HTTP du service d'administration web de RouterOS : une seule requête forgée suffit à exécuter du code en root ou à provoquer un déni de service. Les versions antérieures à 7.24 sont concernées ; la CISA ne relève pas d'exploitation active mais recommande de mettre à jour.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-warns-of-critical-pre-auth-rce-flaw-in-mikrotik-routeros/)

### 🇫🇷 Fisc : le vol de données de la DGFiP est resté invisible sept semaines

Selon le rapport de l'ANSSI, l'attaquant a utilisé des mots de passe volés d'agents de la Direction générale des finances publiques pour extraire, en juin et juillet, les données de centaines de milliers de contribuables et d'entreprises. Ni l'administration ni l'agence n'ont vu les données sortir : l'attaque, peu sophistiquée, a réussi grâce à des mots de passe faibles ou réutilisés.

- **Source** : [The Hacker News](https://thehackernews.com/2026/09/french-tax-data-theft-using-stolen.html)

### 🖥️ TeamViewer : cinq failles sévères à corriger sans attendre

La plus grave, CVE-2026-92370, est un contournement des contrôles d'accès des sessions distantes dans les clients et hôtes Full Client pour Windows, Linux et macOS, exploitable pour exécuter du code à distance. Quatre autres failles (path traversal, débordement de tampon, TOCTOU, validation de chemin) permettent une exécution de code ou une élévation jusqu'à SYSTEM/root ; le correctif est la version 15.82.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/teamviewer-urges-users-to-patch-severe-flaws-as-soon-as-possible/)

### 🔑 543 000 identifiants encore valides exposés dans des dépôts GitHub publics

Plus de 543 000 identifiants trouvés dans des dépôts GitHub publics étaient toujours valides en juillet, malgré les garde-fous de la plateforme. Le volume traduit surtout un problème de rotation : les secrets publiés par erreur restent exploitables longtemps après leur suppression.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/over-543-000-valid-credentials-exposed-in-public-github-repositories/)

## 🚨 À appliquer sans attendre

1. **Cisco Catalyst SD-WAN Manager** (CVE-2026-76504) : mettre à jour immédiatement, aucun contournement n'existe. Chercher l'usage de `%6a` dans les requêtes, et les entrées `j_security_check` d'IP inconnues dans `serviceproxy-access.log` et `vmanage-server.log` — l'exploitation donne un accès admin complet.
2. **Citrix NetScaler ADC / Gateway** (CVE-2026-88772, CVSS 9.5) : patcher, puis auditer la présence de web shells, de comptes superutilisateurs et de configurations exfiltrées. Si le patch ne peut pas être appliqué tout de suite, couper l'exposition Internet des appliances, service DTLS compris.
3. **MikroTik RouterOS** (CVE-2026-84411) : mettre à jour vers 7.23 ou plus récent (7.24.4 stable), et surtout sortir l'interface d'administration web d'Internet — une seule requête non authentifiée suffit pour un RCE en root.
4. **TeamViewer** : passer en version 15.82 sur tous les postes client et hôtes, Windows, Linux et macOS ; les failles corrigées permettent une exécution de code à distance ou une élévation jusqu'à SYSTEM/root.
5. **Hygiène des secrets** : faire tourner les jetons et mots de passe ayant pu transiter par un dépôt GitHub public (543 000 identifiants restaient valides) et vérifier que les agents de codage IA ne publient pas de captures d'écran d'écrans internes — 13 000 images d'entreprise ont déjà fuité ainsi.
