## 💻 CODE & INFORMATIQUE

### 🐡 OpenBSD 8.0 est disponible

L'espace d'adressage virtuel du noyau amd64 passe de 4 Go à 512 Go et la table de pages directe est désormais placée à une adresse aléatoire. La version apporte aussi l'hibernation sur arm64, les pilotes DRM de Linux 6.18.53 avec le support des GPU Intel Arc, et bascule sparc64 sur la chaîne d'outils LLVM.

- **Source** : [OpenBSD](https://www.openbsd.org/80.html) · [HN (191 pts, 54 commentaires)](https://news.ycombinator.com/item?id=50160494)

### 🔐 Go rejettera les chaînes de certificats passant par des intermédiaires jugés non fiables (CVE-2026-111943)

`crypto/x509` filtrera désormais les chaînes contenant un petit ensemble de certificats intermédiaires dont l'exploitation pose problème, empêchant leur retour à l'appelant. L'équipe Go recommande une mise à jour immédiate : des services pourraient cesser de valider des chaînes acceptées jusqu'ici.

- **Source** : [golang/go #82345](https://github.com/golang/go/issues/82345) · [HN (57 pts)](https://news.ycombinator.com/item?id=50160877)

### 🤖 MiniMax M3.1 Flash : 70 % moins cher et près de trois fois plus rapide

Le nouveau modèle « Flash » du laboratoire chinois revendique 73,7 % sur DeepSWE v1.1 et de bons résultats sur les tâches agentiques, le coding et le computer use, pour un coût d'inférence réduit de 70 %. Il est présenté comme la version aboutie de « Space Bunny », le modèle anonyme qui avait consommé plus de 200 000 milliards de tokens.

- **Source** : [MiniMax](https://www.minimax.io/blog/minimax-m31f) · [HN (436 pts, 189 commentaires)](https://news.ycombinator.com/item?id=50154540)

Une ordonnance du département de la sécurité intérieure bannit les modèles DeepSeek des systèmes informatiques des agences fédérales civiles. La mesure s'inscrit dans la série de restrictions visant les modèles d'IA chinois dans l'administration américaine.

## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🧩 Rank Math PRO : un backdoor auto-régénérant distribué pendant onze heures

Les copies de la version pro du plugin SEO WordPress téléchargées sur rankmath.com ou livrées en mise à jour entre le 15 octobre à 20 h 02 et le 16 octobre à 07 h 12 UTC contenaient un malware qui recrée sa porte dérobée à chaque visite du site. Wordfence classe l'incident CVE-2026-111862 à 9,8/10 : installer la version propre 3.0.124 remplace le plugin mais ne supprime ni les fichiers, ni les comptes administrateur, ni les tâches planifiées déposés ailleurs sur le serveur.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/popular-wordpress-seo-plugin-rank-math.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/wordpress-seo-plugin-rank-math-compromised-to-backdoor-websites/)

### 🔑 OpenCode : les clés API de 1,4 % des utilisateurs du Console exposées

L'outil de coding agent open source a subi une attaque par « distillation » à grande échelle ; les clés OpenAI, Anthropic et Google liées au Console ont pu fuiter dès le 17 octobre à 00 h 30 UTC. Des utilisateurs rapportent des factures frauduleuses allant jusqu'à 1 700 dollars et des projets Google Cloud suspendus ; seuls ceux ayant connecté un fournisseur externe sont concernés et ont été prévenus par e-mail.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/opencode-hack-exposes-api-keys-amid-ai-distillation-attacks/) · [The Hacker News](https://thehackernews.com/2026/10/opencode-console-breach-may-have.html)

### 🎬 Plex2Shell : quatre failles de Plex Media Server chaînées pour du RCE non authentifié

La chaîne CVE-2026-96652, CVE-2026-96654, CVE-2026-96655 et CVE-2026-96656 (jusqu'à 8,6) aboutit à une exécution de code à distance sans authentification. Un proof-of-concept public le 16 octobre a été suivi d'attaques dès le lendemain, déployant le mineur XMRig et le proxy inversé Linux « myawesomeproxy » ; les correctifs existent depuis le 3 août dans la version 1.43.3.10861.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/hackers-exploit-plex2shell-flaws-to.html)

### 🌐 F5 publie des correctifs hors cycle pour trois failles critiques de NGINX

CVE-2026-15176 et CVE-2026-97205 (module `ngx_http_v3_module`) ainsi que CVE-2026-93479 (directive `map`) permettent un déni de service, voire une exécution de code sur les configurations non par défaut, via un débordement de tas ou un use-after-free dans le processus worker. F5 n'a pas signalé d'exploitation active et documente des mitigations pour chaque faille.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/f5-releases-out-of-band-patches-for-critical-nginx-vulnerabilities/)

### 📡 Une faille WPS de Broadcom sans correctif ni CVE donne le root à portée de Wi-Fi

Le code WPS de Broadcom réassemble mal les messages d'appairage fragmentés : un attaquant à portée radio peut lire le mot de passe Wi-Fi ou ouvrir un shell distant, sans mot de passe ni étape d'appairage. Les passerelles de trois opérateurs belges (Proximus, Orange Belgium, VOO) sont affectées, et les puces eCos (BCM3380, BCM3383, BCM33834) resteront vulnérables faute de correctif possible.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/unpatched-broadcom-wi-fi-flaw-lets.html)

### 🕵️ GhostAction : un voleur d'identifiants caché dans une fausse police de caractères sur 94 dépôts GitHub

L'acteur derrière la compromission de workflows GitHub Actions passe au phishing ciblant les mainteneurs open source : le domaine `my-github[.]com`, enregistré le 9 octobre, sert une fausse alerte de sécurité GitHub qui relaie la page de connexion et vole mot de passe et code 2FA, avant d'autoriser une application OAuth aux droits `repo`, `workflow` et `read:org`. Quatre-vingt-quatorze dépôts portent le second étage, un stealer déclenché par VS Code et déguisé en fichier de police.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/ghostaction-attackers-plant-credential.html)

### 🇯🇵 Nikkei : troisième fuite de données en un mois, 1,83 million d'enregistrements

Des identifiants dérobés ont servi à accéder à un système de développement le 7 octobre au petit matin. Quelque 150 000 enregistrements contenaient des données personnelles (noms, e-mails, adresses, téléphones, dates de naissance), les 1,68 million restants étant dépourvus d'identifiants ; aucune donnée bancaire n'est concernée.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/nikkei-discloses-third-data-breach-in-a-month-18m-records-exposed/)

## 🚨 À appliquer sans attendre

1. **Rank Math PRO (WordPress)** — si la 3.0.123 a été installée ou activée entre le 15/10 20 h 02 et le 16/10 07 h 12 UTC, considérer le site comme compromis. Mettre à jour en 3.0.124, puis chercher les fichiers PHP déposés dans les dossiers de plugins, de thèmes et de mu-plugins, les comptes administrateur inconnus, un faux fichier de noyau, la règle `.htaccess` faisant exécuter les `.cache` en PHP, les tâches planifiées et les clés SSH. Régénérer tous les secrets accessibles au site (base de données, clés d'API, salts).
2. **OpenCode** — révoquer puis recréer les clés OpenAI, Anthropic et Google utilisées avec le Console OpenCode, et contrôler la facturation ainsi que l'état des projets Google Cloud. L'exposition a commencé le 17/10 à 00 h 30 UTC.
3. **Plex Media Server** — passer en 1.43.3.10861 ou plus récent, puis chercher le binaire `myawesomeproxy`, les scripts récupérant `x12345` via `wget`/`curl` et les connexions sortantes vers 91.92.40.202, 176.65.139.228, 45.194.92.222 et 217.60.194.116.
4. **NGINX** — appliquer les correctifs hors cycle F5. À défaut : retirer les directives `alias` et la variable `$request_filename` des blocs `location` (CVE-2026-15176), désactiver l'AIO et les SSI (CVE-2026-97205), n'utiliser que des captures nommées avec `map` (CVE-2026-93479).
5. **Go** — mettre à jour vers la version embarquant la mitigation CVE-2026-111943 avant que les chaînes concernées ne soient rejetées en production.
6. **Routeurs Broadcom** — désactiver le WPS lorsque l'interface l'autorise ; aucun correctif n'existe pour les puces eCos et aucun CVE n'a été attribué.
7. **Développeurs GitHub** — vérifier les applications OAuth autorisées sur son compte, en révoquer toute inconnue, et se méfier des alertes de connexion renvoyant vers `my-github[.]com`.
