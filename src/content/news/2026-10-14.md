## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🪟 Patch Tuesday record : Microsoft corrige 1 411 failles, dont une zero-day exploitée

Le Patch Tuesday d'octobre bat un record avec 1 411 vulnérabilités corrigées, dont 70 critiques. Une faille zero-day est activement exploitée — **CVE-2026-96951** (contournement de la fonction Mark of the Web par injection de commande dans Windows Shell) — aux côtés de deux zero-days divulguées : **CVE-2026-108398** (.NET Framework, contournement de WDAC) et **CVE-2026-92707** (déni de service MessagePack-CSharp). Microsoft rappelle aussi la fin du support de Windows 11 24H2 (Home et Pro) et de Windows 10 Enterprise LTSB 2016.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-october-2026-patch-tuesday-fixes-1-411-flaws-3-zero-days/) · [The Hacker News](https://thehackernews.com/2026/10/microsoft-patches-record-1413-flaws.html)

### 🔓 Ivanti Connect Secure : un zero-day d'authentification exploité et enchaîné

**CVE-2026-104935**, un contournement d'authentification sans privilège et sans interaction utilisateur, est exploité depuis au moins le 3 octobre sur les passerelles Ivanti Connect Secure. Le groupe UTA0576 a enchaîné cette faille avec deux autres pour obtenir une exécution de code root non authentifiée sur des appliances pourtant à jour, sans déposer de malware, en effaçant ses traces pour tromper l'Integrity Checker Tool ; une faille d'escalade reste non corrigée. Plus de 5 500 instances ICS seraient exposées sur Internet. Versions affectées : 22.8R2.4 et antérieures, 25.1.2.2 et antérieures, 25.1.1.1 et antérieures.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/ivanti-warns-of-connect-secure-zero-day-exploited-in-attacks/) · [The Hacker News](https://thehackernews.com/2026/10/attacker-chains-three-ivanti-connect.html)

### 🧾 SAP : une faille maximale (SSRF OAuth2) dans le Cloud SDK pour Python

SAP a corrigé une vulnérabilité de sévérité maximale (**CVE-2026-89111**) dans son Cloud SDK pour Python, utilisé pour bâtir agents IA et applications sur la plateforme BTP. Un attaquant contrôlant le paramètre `tenant_subdomain` peut rediriger les requêtes de jeton OAuth2 vers son propre serveur et exfiltrer les identifiants client des applications multi-tenant. En attendant le correctif, valider `tenant_subdomain` contre une liste blanche.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-oauth2-ssrf-security-flaw/) · [The Hacker News](https://thehackernews.com/2026/10/sap-discloses-critical-cvss-10-flaw-in.html)

### 📄 Ghostscript : exécution de code à distance via un PDF piégé

**CVE-2026-39919**, un débordement de tampon critique dans l'interpréteur Ghostscript, permet une exécution de code à distance via un PDF piégé (image JPEG 2000) pouvant écrire 1 024 octets dans un tampon de 256. Toutes les versions de 9.21 à 10.07.1 sont affectées ; le correctif est disponible en 10.08.0 (avec rétroportages). Le vecteur privilégié est WordPress via Imagick, mais tout service générant des aperçus de PDF est concerné ; aucune exploitation dans la nature n'a encore été observée.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/ghostscript-flaw-lets-hackers-hijack-servers-via-pdf-uploads/)

### 🐳 Docker Hub : un jeton personnel réaffecté permettait d'usurper des comptes

**CVE-2026-105445**, une faille critique présente depuis août 2024, permettait à un attaquant de créer un compte et un jeton d'accès personnel (PAT), de convertir le compte en organisation puis de désigner la victime comme propriétaire — le jeton héritant de ses droits sans rotation ni consentement. Il devenait alors possible de tirer, pousser ou supprimer des images sous une identité légitime, un risque jugé « critique » pour la chaîne d'approvisionnement. Docker a corrigé en production en moins de quatre heures et indique n'avoir trouvé aucune preuve d'exploitation ; les jetons transférés ont été désactivés le 8 octobre.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/docker-hub-flaw-let-attackers-impersonate-users-tamper-with-images/) · [The Hacker News](https://thehackernews.com/2026/10/docker-fixes-critical-two-year-old-hub.html)

## 🚨 À appliquer sans attendre

1. **Windows / Patch Tuesday d'octobre — déployer** : les mises à jour corrigent CVE-2026-96951 (zero-day exploitée, contournement de Mark of the Web) et CVE-2026-108398 (.NET Framework, contournement de WDAC). Vérifier aussi les fins de support Windows 11 24H2 (Home et Pro) et Windows 10 LTSB 2016.
2. **Passerelles Ivanti Connect Secure — patcher d'urgence** : CVE-2026-104935 est exploitée pour une exécution de code root sur des appliances à jour, avec des variantes d'exploitation en chaîne. Une faille d'escalade reste non corrigée : isoler ou retirer les VPN exposés si la mise à jour n'est pas possible, et faire tourner l'Integrity Checker Tool.
3. **SAP Cloud SDK pour Python — mettre à jour** : CVE-2026-89111 (CVSS maximal, SSRF OAuth2). À défaut, valider `tenant_subdomain` via une liste blanche avant tout appel SDK ; envisager la rotation des identifiants client exposés.
4. **Ghostscript — passer en 10.08.0** : tous les serveurs générant des aperçus de PDF (WordPress via Imagick, pipelines Docker/ImageMagick) sont concernés par CVE-2026-39919. Si la mise à jour est impossible, bloquer les uploads PDF ou désactiver le rendu PDF dans ImageMagick.
5. **Docker Hub — vérifier les jetons** : si vous avez reçu une notification Docker autour du 2 octobre, considérez vos PAT comme potentiellement exposés (rotation) ; les jetons transférés ont été désactivés le 8 octobre.
6. **npm / chaîne d'approvisionnement** : après le durcissement côté GitHub, auditer les droits de publication de vos paquets et privilégier l'authentification forte (2FA, trusted publishing) plutôt que des jetons statiques.
