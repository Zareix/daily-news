## 🇫🇷 FRANCE

### 📢 Grève du 29 septembre : 338 lycées bloqués, dix blessés

La mobilisation interprofessionnelle de ce mardi a donné lieu à des blocages dans 338 établissements scolaires, selon le ministère de l'éducation nationale, et à dix blessés. Les cortèges défilent à Paris, Lyon ou Marseille pour réclamer des hausses de salaires et davantage de moyens, dans un contexte de nouveau gel des salaires dans la fonction publique.

- **Sources** : [Le Monde](https://www.lemonde.fr/societe/article/2026/09/29/greve-du-29-septembre-les-premiers-corteges-defilent-pour-demander-davantage-de-moyens_6785560_3225.html) · [Le Monde](https://www.lemonde.fr/societe/article/2026/09/29/blocages-des-lycees-338-etablissements-concernes-et-dix-blesses-selon-le-ministere-de-l-education-nationale_6785573_3225.html)

### 💰 Dette publique : 119 % du PIB, du jamais-vu depuis 1946

La dette publique française s'envole à 119 % du PIB, un niveau inédit depuis 1946, alors que le gouvernement prépare le budget 2027. Le sujet place la France au cœur des inquiétudes internationales sur la soutenabilité de ses finances.

- **Source** : [Le Monde](https://www.lemonde.fr/politique/article/2026/09/29/la-dette-publique-s-envole-a-119-du-pib-du-jamais-vu-depuis-1946_6785566_823448.html)

### 🏛️ Municipales : la justice annule l'élection de Vénissieux

La justice a annulé les élections municipales de Vénissieux, près de Lyon, remportées par LFI, en raison d'irrégularités sur la liste RN-UDR. La décision relance la bataille pour la mairie de cette commune de la métropole lyonnaise.

## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🐛 Citrix NetScaler : deux zero-days RCE exploités mondialement (CVE-2026-88771, CVE-2026-88772)

Deux vulnérabilités critiques de NetScaler ADC et Gateway permettent à un attaquant non authentifié d'exécuter du code à distance — CVE-2026-88771, notée 9,5 de sévérité, et CVE-2026-88772. La première touche toutes les configurations par défaut ; la seconde nécessite DTLS, actif par défaut sur les serveurs virtuels VPN. Citrix a confirmé l'exploitation active et CISA a inscrit les deux failles à son catalogue KEV, avec une échéance de correction fixée à mercredi pour les agences fédérales américaines.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-orders-feds-to-patch-exploited-citrix-flaws-by-wednesday/) · [The Hacker News](https://thehackernews.com/2026/09/cisa-says-attackers-are-exploiting-two.html)

### 🍎 Apple corrige un zero-day CoreGraphics exploité dans des attaques ciblées (CVE-2026-86950)

Cette écriture hors limites dans CoreGraphics permet une exécution de code arbitraire lors du traitement d'un fichier piégé, et a été exploitée dans des attaques « extrêmement sophistiquées » visant des individus précis. Le correctif est disponible dans iOS et iPadOS 26.7.1, macOS Tahoe 26.7.1 et macOS Sequoia 15.8.1 ; les iPhone 11 et modèles ultérieurs sont concernés.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/apple-patches-coregraphics-zero-day-flaw-exploited-in-attacks/) · [The Hacker News](https://thehackernews.com/2026/09/apple-patches-coregraphics-flaw.html)

### 🧩 MCP Python SDK : un serveur malveillant peut récupérer vos identifiants OAuth

Dans les versions antérieures à 1.30.0, un serveur MCP piégé peut amener un client à transmettre le secret d'application, le code d'autorisation et la clé de preuve PKCE vers un point d'échange de jetons qu'il contrôle. Le correctif est publié en version 1.30.0 : toute application s'appuyant sur ce SDK doit être mise à jour.

- **Source** : [The Hacker News](https://thehackernews.com/2026/09/official-mcp-python-sdk-flaw-can-let.html)

### 🗄️ Supabase : plus de 16 000 bases de données exposent PII, mots de passe et jetons

UpGuard a identifié plus de 16 000 bases Supabase mal configurées dont les tables sont lisibles publiquement ; dans plus de la moitié des cas figurent des données personnelles, parfois des mots de passe et des jetons d'authentification. La cause est une politique RLS absente ou mal définie, à vérifier sur tout projet Supabase exposé.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/misconfigured-supabase-apps-expose-data-in-over-16-000-databases/)

### 🕵️ ShinyHunters : un homme de 24 ans arrêté à Amsterdam

La police néerlandaise a confirmé l'arrestation, plus tôt ce mois-ci, d'un habitant d'Amsterdam de 24 ans dans le cadre de l'enquête sur le groupe cybercriminel ShinyHunters. Il doit être présenté à un juge d'instruction.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/09/dutch-police-arrest-24-year-old.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/dutch-police-confirm-arrest-in-shinyhunters-hacking-investigation/)

### 🐳 Docker : le botnet Carbonato exploite les démons exposés pour déployer un agent IA

Le botnet Carbonato cible les démons Docker accessibles depuis Internet et y installe un framework d'agent IA open source piloté par Telegram, en réécrivant son fichier de personnalité pour exécuter les ordres de l'attaquant. Toute API Docker exposée sans authentification constitue un point d'entrée.

- **Source** : [The Hacker News](https://thehackernews.com/2026/09/carbonato-botnet-compromises-docker.html)

### 🇯🇵 Japon : Times Car reconnaît 6,6 millions de comptes exposés, Keio touché par un rançongiciel

L'exploitant japonais d'autopartage Times Car a confirmé qu'environ 6,6 millions de comptes utilisateurs ont été compromis lors d'une cyberattaque. La même semaine, l'opérateur ferroviaire Keio a reconnu qu'un rançongiciel avait perturbé plusieurs de ses systèmes métiers.

## 🚨 À appliquer sans attendre

1. **Citrix NetScaler** : patcher d'urgence (CVE-2026-88771 / CVE-2026-88772) — exécution de code à distance sans authentification, exploitation active documentée. Si le correctif ne peut pas être appliqué immédiatement, retirer l'interface d'administration du NetScaler de l'exposition Internet.
2. **Apple** : installer iOS/iPadOS 26.7.1, macOS Tahoe 26.7.1 ou macOS Sequoia 15.8.1 (CVE-2026-86950) — exploitation ciblée confirmée.
3. **MCP Python SDK** : passer en version 1.30.0 ou ultérieure — les versions antérieures transmettent les identifiants OAuth à un serveur malveillant.
4. **Supabase** : vérifier que le RLS est activé sur toutes les tables atteignables via l'API (plus de 16 000 bases publiques recensées).
5. **Docker** : ne jamais exposer l'API du démon Docker sur Internet — le botnet Carbonato en fait son vecteur d'entrée.
