## 💻 CODE & INFORMATIQUE

### 🧠 « L'IA ne remplace pas les SRE, elle les déqualifie »

Le billet le plus discuté de la journée sur Hacker News (plus de 570 points, 420 commentaires) défend l'idée que l'assistance par IA érode les compétences opérationnelles des ingénieurs fiabilité : on diagnostique moins soi-même, donc on comprend moins les systèmes quand ils cassent. Un débat qui recoupe les inquiétudes sur la perte de maîtrise des incidents en production.

- **Source** : [Signoz](https://newsletter.signoz.io/p/ai-isnt-replacing-sres-its-deskilling)

### 🌐 Les forges de code fédérées sortent de la théorie

Tangled, forge Git fédérée bâtie sur AT Protocol, publie un billet de fond très commenté sur ce que change une forge où les dépôts, issues et identités ne dépendent pas d'une plateforme unique. L'argument central : reprendre la main sur le graphe social du développement plutôt que sur un simple hébergement de dépôts.

- **Source** : [Tangled](https://tangled.org/blog/forge/)

### 🦀 Sanstun : WireGuard en Rust, sans I/O

Firezone présente Sanstun, une implémentation de WireGuard en Rust conçue sans entrées-sorties intégrées (« sans-IO »), donc testable de façon déterministe et parallélisable, pensée pour s'intégrer à des runtimes variés. Une approche qui intéresse autant les équipes réseau que celles qui écrivent des bibliothèques protocolaires.

- **Source** : [Firezone](https://www.firezone.dev/blog/introducing-sanstun)

### 🎮 Une NES qui tourne dans 1 Go de poids Qwen

Un projet Show HN fait tourner un émulateur Nintendo dans environ 1 Go de poids du modèle Qwen, avec un rendu approximatif mais fonctionnel — 238 points et près de 120 commentaires. L'occasion de mesurer ce qu'un petit modèle peut apprendre d'un système à états discrets, et où l'approche casse.

- **Source** : [GitHub — nesformer](https://github.com/dbreunig/nesformer)

## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🐧 Faille critique du noyau Linux : root distant via MPTCP

Des chercheurs d'Anthropic ont développé un exploit pour une vulnérabilité critique du noyau Linux permettant à un attaquant non authentifié d'exécuter des commandes en root à distance sur des serveurs exposant MPTCP. Toute machine avec le support MPTCP activé et joignable doit être considérée comme exposée jusqu'au correctif.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-linux-kernel-flaw-allows-remote-root-attacks-on-mptcp-servers/)

### 🧩 Extension Claude Code trojanisée sur le marketplace Cursor

Une version malveillante de l'extension VS Code officielle d'Anthropic a été diffusée via le marketplace de Cursor pendant environ onze heures le 29 octobre, avec un backdoor SSH persistant, exposant jusqu'à 5 000 développeurs. Si vous avez installé ou mis à jour l'extension Claude Code depuis Cursor cette semaine, il faut inspecter les clés SSH autorisées et les processus persistants.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/malicious-claude-code-extension-on-cursor-planted-ssh-backdoors/) · [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html)

### 🦊 GitLab : la faille de sévérité maximale désormais exploitée

La CISA confirme l'exploitation active d'une vulnérabilité GitLab de sévérité maximale corrigée plus tôt ce mois-ci. Les instances auto-hébergées non mises à jour doivent être patchées en priorité, l'accès aux dépôts et aux jetons CI pouvant servir de point d'entrée.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-now-exploiting-max-severity-gitlab-flaw-in-attacks/)

### 🛒 Drupal Commerce Core : bypass d'autorisation exploité (CVE-2026-118539)

Drupal alerte sur l'exploitation active d'une faille « highly critical » dans le module Commerce Core, un contournement d'autorisation référencé CVE-2026-118539. Les sites e-commerce sous Drupal Commerce doivent être mis à jour sans attendre, le module étant massivement déployé.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/10/hackers-actively-exploit-highly.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/drupal-warns-of-critical-commerce-core-flaw-exploited-in-attacks/)

### 💬 Un lien de partage ChatGPT pouvait exécuter du code dans votre session

Des chercheurs ont montré qu'un lien de conversation ChatGPT malveillant pouvait exécuter du code dans la session connectée de la personne qui l'ouvre, et donc lire ses échanges privés. Le vecteur est le lien partagé lui-même : ne pas ouvrir de partages ChatGPT non sollicités, surtout depuis un compte contenant des données sensibles.

- **Source** : [The Hacker News](https://thehackernews.com/2026/10/a-shared-chatgpt-link-could-run.html)

## 🚨 À appliquer sans attendre

1. **Noyau Linux / MPTCP** : identifier les serveurs avec MPTCP activé et exposés sur Internet, appliquer le correctif noyau de votre distribution, ou désactiver MPTCP en attendant.
2. **GitLab** : vérifier la version et mettre à jour vers le correctif publié ce mois-ci — exploitation confirmée dans la nature par la CISA.
3. **Drupal Commerce Core** : appliquer la mise à jour du module (CVE-2026-118539), l'exploitation est en cours.
4. **WordPress** : près de 63 000 tentatives d'exploitation en 24 h sur une faille RCE critique du cœur, sans identifiant CVE — mettre à jour le cœur et vérifier les comptes administrateurs.
5. **Poste de développeur** : si l'extension Claude Code a été installée depuis le marketplace Cursor le 29 octobre, chercher un backdoor SSH (clés ajoutées dans `~/.ssh/authorized_keys`, processus et services persistants) et révoquer les secrets exposés.
