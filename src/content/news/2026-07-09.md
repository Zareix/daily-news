## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🪟 Microsoft patche la faille RoguePlanet dans Defender (CVE-2026-50656)

Une vulnérabilité zero-day dans le moteur de Microsoft Defender permettait une escalade de privilèges jusqu'au niveau SYSTEM (CVSS 7.8). Le correctif est disponible. ⚠️ **À appliquer d'urgence.**

- **Source** : [The Hacker News](https://thehackernews.com/2026/07/microsoft-patches-rogueplanet-defender.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-patches-rogueplanet-defender-zero-day-vulnerability/)

### 🐧 GhostLock : 15 ans de faille kernel Linux permettant le root (CVE-2026-43499)

Présente dans le noyau depuis 2011, cette vulnérabilité permet à n'importe quel utilisateur connecté d'obtenir les droits root sans permission spéciale. Affecte toutes les distributions majeures.

- **Source** : [The Hacker News](https://thehackernews.com/2026/07/15-year-old-ghostlock-flaw-enables-root.html)

### 🖥️ 16 ans de faille KVM « Januscape » : évasion de VM guest vers host (CVE-2026-53359)

Un use-after-free dans KVM permet à une VM invitée de corrompre le noyau hôte sur Intel et AMD. Un PoC public panique l'hôte ; des exploits plus avancés existeraient.

- **Source** : [The Hacker News](https://thehackernews.com/2026/07/16-year-old-linux-kvm-flaw-lets-guest.html)

### 🤖 GhostApproval : 6 assistants de code AI vulnérables aux symlinks malveillants

Des chercheurs de Wiz ont découvert qu'un simple lien symbolique permet à un repo piégé d'écrire dans des fichiers sensibles après avoir demandé l'approbation pour un fichier inoffensif. Affecte Claude Code, Cursor, Windsurf, Amazon Q Developer, Augment, Google Antigravity.

- **Source** : [The Hacker News](https://thehackernews.com/2026/07/ghostapproval-symlink-flaws-could-let.html)

### 📦 HalluSquatting : quand les hallucinations des IA créent des failles de supply chain

Des chercheurs ont découvert que les assistants AI inventent régulièrement des noms de packages qui n'existent pas. En enregistrant ces noms à l'avance, un attaquant peut faire installer son malware par l'IA.

- **Source** : [The Hacker News](https://thehackernews.com/2026/07/new-hallusquatting-attack-could-trick.html)

### 🚨 Ubiquiti : faille critique 10.0 dans UniFi OS + 6 autres CVE

Commande injection et escalade de privilèges. Mettre à jour immédiatement UniFi OS, Connect, Talk, Access et Protect.

## 🚨 À appliquer sans attendre

1. **Correctifs critiques** : Microsoft Defender (RoguePlanet), noyau Linux (GhostLock), Ubiquiti UniFi OS (CVSS 10.0), Adobe ColdFusion (exploitation active au catalogue KEV de la CISA).
2. **Agents de code AI** : GhostApproval et Friendly Fire montrent qu'un repo piégé peut faire exécuter du code malveillant à Claude Code, Codex ou Cursor. Ne rien lancer en mode autonome sur une source non vérifiée, et contrôler les dépendances suggérées par un assistant (HalluSquatting).
3. **Phishing avancé** : la campagne « ghost phishing » utilise des pages qui ne se déchiffrent que dans le navigateur de la victime, court-circuitant les filtres d'URL classiques.
