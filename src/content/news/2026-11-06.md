## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🐧 OpenSSH : correctif d'urgence pour un contournement d'authentification sur Alpine

Une faille surnommée « *sshole » permet à un attaquant disposant d'un accès réseau de se connecter à des comptes configurés sans mot de passe — notamment les comptes à clé SSH uniquement — sur des serveurs Alpine Linux et autres distributions basées sur musl utilisant le paquet openssh-server standard. Un correctif a été publié en urgence par OpenSSH : toute instance Alpine exposée doit être mise à jour immédiatement.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/openssh-issues-emergency-fix-for-flaw.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/openssh-flaw-lets-attackers-log-into-password-disabled-linux-accounts/)

### 🖥️ CWPdoor : des serveurs Linux compromis via un cwpsrv trojanisé

Les chercheurs de QiAnXin XLab ont identifié CWPdoor, un malware Linux diffusé par une version trojanisée de cwpsrv, le serveur web derrière l'interface d'administration Control Web Panel (CWP). La backdoor permet d'exécuter des commandes sans laisser de traces dans les journaux, ce qui rend la détection a posteriori difficile.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/hackers-hide-linux-backdoor-in-control.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-backdoor-linux-servers-using-trojanized-cwp-web-server/)

### 📨 Barracuda ESG : deux failles chaînées donnent un accès root sans authentification

Deux vulnérabilités de la passerelle de filtrage mail Barracuda Email Security Gateway peuvent être enchaînées pour exécuter des commandes en root sans aucune connexion préalable. L'éditeur a publié des correctifs ; les appliances exposées sur Internet doivent être patchées sans attendre.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/experts-demonstrate-barracuda-email.html)

### 🎣 Faux événements OpenAI, SpaceX et Anthropic : du phishing pour voler les comptes Microsoft et Google

Des campagnes utilisent de fausses invitations à des événements OpenAI, SpaceX et Anthropic pour piéger des salariés, via deux plateformes de phishing-as-a-service distinctes. L'objectif est le vol d'identifiants Microsoft et Google, donc l'accès aux messageries et à l'écosystème bureautique des entreprises ciblées.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/fake-openai-spacex-events-used-to-steal-microsoft-google-accounts/)

### 🪪 DigiCert : fuite de données clients et de documents d'identité

DigiCert révèle une violation après qu'une migration de serveur a exposé par erreur un système métier interne sur Internet, permettant un accès non autorisé à des informations clients et à des pièces d'identité. L'autorité de certification n'a pas précisé le volume de personnes concernées.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/digicert-data-breach-exposes-customer-information-identity-documents/)

## 🚨 À appliquer sans attendre

1. **OpenSSH sur Alpine/musl** : mettre à jour `openssh-server` dès que le correctif est disponible dans les dépôts ; vérifier en priorité les serveurs avec comptes à clé uniquement et SSH exposé sur Internet. Contournement d'authentification sans interaction utilisateur.
2. **Control Web Panel (CWP)** : si un serveur fait tourner CWP/cwpsrv, considérer l'hôte comme potentiellement compromis — la backdoor CWPdoor efface ses traces. Isoler, réinstaller depuis une source propre, puis rechercher les connexions sortantes anormales.
3. **Barracuda Email Security Gateway** : appliquer les correctifs éditeur ; l'enchaînement de failles donne du root sans authentification sur une appliance exposée.
4. **Phishing « événements »** : sensibiliser sur les invitations OpenAI / SpaceX / Anthropic non sollicitées — elles servent à voler les sessions Microsoft 365 et Google Workspace. Vérifier le domaine expéditeur et activer les clés d'accès résistantes au phishing (FIDO2) sur les comptes à privilèges.
