## 🇫🇷 FRANCE

### 🏫 Blocages des lycées : dix jours de mobilisation, le pouvoir durcit le ton

## 💻 CODE & INFORMATIQUE

### 🤖 Pi 1.0 : l'agent de codage minimaliste passe en version stable

Earendil publie Pi 1.0, un « harness » d'agent durci et minimal qui ajoute le Codemode (support natif de MCP), le chargement différé des outils et le réchauffement de cache pour les modèles Anthropic. La société lance en parallèle Pi Durable, un paquet expérimental pour des applications agentiques de longue durée ; les deux sont sous licence MIT.

- **Source** : [Earendil](https://earendil.com/posts/pi-1-0/) · [HN (1089 pts)](https://news.ycombinator.com/item?id=49926069)

### 🧩 SvelteKit 3 est disponible

La version 3 du framework applicatif de Svelte mise sur le polissage et la sûreté de typage : la configuration migre dans `vite.config.ts`, l'alias `$lib` devient `#lib` via les subpath imports de Node, et la gestion des variables d'environnement, des service workers et des erreurs est revue. Une commande `npx sv migrate sveltekit-3` automatise la majeure partie de la migration.

- **Source** : [Svelte](https://svelte.dev/blog/sveltekit-3-is-here) · [HN (219 pts)](https://news.ycombinator.com/item?id=49926536)

### 🐋 DeepSeek ouvre son agent « Harness » en preview

DeepSeek lance en preview publique et en open source DeepSeek Harness, un agent construit sur l'architecture « everything is a plugin » de Cordis, utilisable en application de bureau ou via une interface web. Il couvre le travail courant, le code, la recherche et les tâches de fond, avec des plugins tiers installables ou générables via un « Creator mode ».

- **Source** : [DeepSeek](https://www.deepseek.com/en/harness/) · [HN (166 pts)](https://news.ycombinator.com/item?id=49929489)

### 🐧 Debian corrige une large vague de failles du noyau Linux

L'avis de sécurité DSA-6528-1 corrige des centaines de CVE du noyau Linux pouvant mener à une élévation de privilèges, un déni de service ou des fuites d'informations ; le correctif est publié en version 6.12.111-1 pour la branche stable (trixie). La CISA a par ailleurs alerté sur l'exploitation active de plusieurs failles du noyau.

- **Sources** : [LWN.net](https://lwn.net/Articles/1097401/) · [HN (233 pts)](https://news.ycombinator.com/item?id=49928121) · [Debian](https://www.debian.org/security/)

## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🛡️ FortiMail : un zero-day critique exploité, ajouté au KEV

La CISA a inscrit au catalogue KEV la faille CVE-2026-104286 (CVSS 9.8) affectant Fortinet FortiMail, qui permet à un attaquant non authentifié d'écrire des fichiers arbitraires sur le système. Fortinet confirme une exploitation active en zero-day ; la mise à jour doit être appliquée sans attendre.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/10/critical-fortimail-zero-day-flaw.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/fortinet-warns-of-critical-fortimail-flaw-exploited-in-zero-day-attacks/)

### 🌐 Cisco Catalyst SD-WAN Manager : contournement d'authentification exploité

La faille CVE-2026-76504 (CVSS 9.8) permet à un attaquant distant non authentifié d'utiliser l'API du Manager avec les droits de l'administrateur ; elle est activement exploitée et vient d'être ajoutée au KEV. Des versions corrigées sont disponibles et Cisco indique qu'il n'existe aucun contournement.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/10/cisa-adds-exploited-cisco-catalyst-sd.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisco-warns-of-new-sd-wan-authentication-bypass-zero-day-exploited-in-attacks/)

### 📡 MikroTik RouterOS : RCE pré-authentifié critique

CVE-2026-84411 est un underflow d'entier dans le traitement des requêtes HTTP de l'interface d'administration web : une seule requête forgée peut donner une exécution de code en root ou provoquer un déni de service. Les versions inférieures à 7.24 sont concernées ; aucune exploitation active n'est confirmée, mais les failles MikroTik sont très prisées des botnets.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-warns-of-critical-pre-auth-rce-flaw-in-mikrotik-routeros/)

### 🪖 Pentagone : plus de 3 millions de personnes touchées par une fuite

Le Defense Manpower Data Center notifie des millions de militaires après l'intrusion, entre octobre 2025 et juillet 2026, dans son système de gestion des ressources humaines via une vulnérabilité de ses outils de partage de fichiers. Les données volées incluent numéros de sécurité sociale, noms, dates de naissance et informations militaires.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-breach-pentagon-human-resources-management-system-steal-data-of-nearly-3-million-people/)

### 🔑 543 000 identifiants encore valides exposés sur GitHub

Une analyse de 224 millions de dépôts montre que plus de 543 000 identifiants trouvés dans des dépôts publics étaient toujours valides en juillet, avec une durée médiane d'exposition de 784 jours. La moitié environ relève de catégories que la Push Protection de GitHub ne bloque pas, comme les chaînes de connexion à des bases de données.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/over-543-000-valid-credentials-exposed-in-public-github-repositories/)

L'opération internationale « KillSwitch » a saisi le site de fuite et les serveurs de KillSec, conduit à trois arrestations et identifié un jeune de 16 ans comme l'administrateur présumé du groupe. KillSec dérobait des données d'organisations et menaçait de les publier pour obtenir une rançon.

## 🚨 À appliquer sans attendre

1. **FortiMail** (CVE-2026-104286, CVSS 9.8) : appliquer la mise à jour Fortinet dès que possible — exploitation active en zero-day, écriture de fichiers arbitraires sans authentification, inscrite au KEV (échéance fédérale américaine).
2. **Cisco Catalyst SD-WAN Manager** (CVE-2026-76504, CVSS 9.8) : patcher immédiatement, aucun contournement n'existe ; rechercher les accès API inhabituels effectués avec les droits admin.
3. **MikroTik RouterOS** (CVE-2026-84411) : mettre à jour vers 7.23 ou plus récent (7.24.4 stable) et surtout retirer l'interface d'administration web d'Internet — une seule requête non authentifiée suffit pour un RCE en root.
4. **Noyau Linux** : déployer l'avis Debian DSA-6528-1 (version 6.12.111-1 pour trixie) et suivre les failles du noyau activement exploitées signalées par la CISA sur les autres distributions.
5. **Hygiène des secrets** : faire tourner les identifiants ayant pu transiter par un dépôt GitHub public, scanner l'historique des dépôts et fixer une expiration automatique — 543 000 identifiants restaient valides, avec une exposition médiane de plus de deux ans.
