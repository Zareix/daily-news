- **Source** : [The Hacker News](https://thehackernews.com/2026/11/vmware-vcenter-hit-by-another-critical.html)

### 🔌 WordPress retire six extensions WP Connect piégées avant leur publication

Six plugins développés par WP Connect ont été backdoorés le 22 novembre 2026 pour permettre l’exécution arbitraire de code sur les sites qui les installent, et bloqués avant leur diffusion. Tout site ayant déjà ces extensions doit les supprimer et chercher des traces d’exécution de code.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/wordpress-blocks-six-backdoored-wp.html)

## 🚨 À appliquer sans attendre

1. **VMware vCenter / ESX** : appliquer les 23 correctifs de Broadcom en priorité, la faille 9,8 de contournement d’authentification ayant déjà servi en zero-day — isoler les consoles vCenter du réseau avant le patch si l’exposition est directe.
2. **Check Point Security Management** : restreindre l’accès Internet des consoles, patcher, puis auditer comptes administrateurs et secrets — la compromission de 24 serveurs dans 22 organisations suppose un vol d’identifiants.
3. **WordPress** : vérifier la présence d’extensions WP Connect, les désinstaller, et scanner les fichiers pour du code PHP injecté depuis le 22 novembre.
4. **SSO et cloud** : basculer les comptes critiques vers une authentification résistante au phishing (clés FIDO2, passkeys), vérifier les journaux d’enrôlement MFA et de connexion depuis août 2026 (vishing INCEPTION / ShinyHunters), et révoquer les sessions suspectes.
5. **Clés cloud** : faire tourner les secrets si vous êtes client de Radware (clés d’accès cloud exposées) et migrer hors de Rackspace Spot avant le 8 décembre ; considérer les données Turnitin comme potentiellement exfiltrées côté utilisateurs.
6. **Pare-feu applicatifs internes** : l’incident Radware vient d’un Cloud WAF interne non sécurisé — vérifier l’authentification et la segmentation de vos propres consoles d’administration.
