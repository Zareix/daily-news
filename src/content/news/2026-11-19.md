## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🐘 PHP : des failles critiques dans toutes les versions supportées, correctifs ce jour

Les mainteneurs de PHP ont publié mercredi un avis annonçant une release de sécurité corrigeant des vulnérabilités critiques affectant l'ensemble des branches supportées, planifiée pour le 19 novembre 2026. Aucun détail technique n'a été divulgué avant la publication des correctifs.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/php-warns-of-critical-security-flaws.html)

### 🕸️ NGINX : une faille HTTP/2 vieille de dix ans permet l'exécution de code

CVE-2026-123007, surnommée « nginx2root », permet à un attaquant non authentifié d'exécuter du code sur les serveurs où HTTP/2 est activé. La faille dormait dans le code depuis une décennie.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html)

### ☕ Java4Shell (CVE-2026-114938) : RCE pré-authentification sur Jira, Jenkins, Keycloak

Une faille dans OpenJDK permet à un attaquant sans compte d'exécuter son propre code sur six applications d'entreprise très répandues, dont Jira, Jenkins et Keycloak. Les chercheurs de Calif qui l'ont identifiée parlent d'un nouveau « Log4Shell » par sa portée.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/java4shell-cve-2026-114938-enables-pre.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-java4shell-flaw-allows-rce-attacks-on-major-java-applications/)

### 📝 Apache Roller : un RCE critique exploité activement, sans authentification

La fondation Apache a publié des mises à jour pour une faille critique de la plateforme de blogs Java, déjà exploitée dans la nature pour obtenir l'exécution de code sur les serveurs vulnérables. Aucune authentification n'est requise.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/critical-apache-roller-rce-flaw-under.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/apache-warns-of-roller-rce-vulnerability-exploited-in-attacks/)

### 📦 Le paquet PyPI « Agent Framework » de Microsoft compromis

Deux versions malveillantes du paquet officiel ont été publiées, conçues pour exfiltrer des identifiants cloud et d'autres informations sensibles depuis les machines de développeurs. Toute installation récente doit être considérée comme compromise.

- **Source** : [BleepingComputer](https://www.bleepingcomputer.com/news/security/microsofts-agent-framework-pypi-package-compromised-to-steal-credentials/)

## 🚨 À appliquer sans attendre

1. **PHP** : mettre à jour vers les versions de sécurité publiées ce 19 novembre dès qu'elles sont disponibles — toutes les branches supportées sont concernées.
2. **Java4Shell** : identifier les instances Jira, Jenkins, Keycloak et applications Java comparables exposées, puis appliquer le correctif OpenJDK ; à traiter comme un Log4Shell.
3. **Apache Roller** : l'exploitation est active et ne demande aucun compte — patcher ou couper l'accès public immédiatement.
4. **NGINX** : patcher les serveurs avec HTTP/2 activé, ou désactiver HTTP/2 en attendant ; CVE-2026-123007 donne un accès root non authentifié.
5. **Chaîne d'approvisionnement Python** : vérifier la version du paquet `agent-framework` de Microsoft, désinstaller les versions compromises et renouveler les identifiants cloud exposés.
6. **F5 BIG-IP et Puppet** : six failles critiques (crash du TMM, RCE potentiel) côté F5, RCE Puppet ajouté au catalogue KEV de la CISA — deux chantiers de patch à planifier cette semaine.
