## 💻 CODE & INFORMATIQUE

### 🔧 Git 2.56.1 corrige une exécution de code au clone récursif

Une faille permettait à un dépôt malveillant de faire exécuter du code à la machine qui le clone récursivement, avec ses sous-modules. Le projet Git a publié le correctif cette semaine dans la version 2.56.1 ; toute chaîne d'intégration qui clone des dépôts tiers est concernée.

- **Source** : [The Hacker News](https://thehackernews.com/2026/11/git-patches-flaw-that-lets-malicious.html)

## 🔒 CYBERSÉCURITÉ & FUITES DE DONNÉES

### 🪟 Patch Tuesday record : 1 235 failles, un zero-day Outlook

Microsoft a corrigé un nombre record de 1 235 vulnérabilités dans ses mises à jour de novembre, dont une faille zero-day dans Outlook exploitée activement. Les cumulatifs Windows 11 (KB5132061, KB5131087) et la mise à jour de sécurité étendue Windows 10 (KB5131096) sont disponibles.

- **Sources** : [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-november-2026-patch-tuesday-fixes-1-235-flaws-outlook-zero-day/) · [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-windows-10-kb5131096-extended-security-update/)

### 🖥️ Xen Orchestra : un contournement d'authentification critique exploité

Aucun contournement n'est documenté : la mise à jour est la seule protection.

- **Sources** : [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-xen-orchestra.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-xen-orchestra-auth-bypass-flaw-exploited-to-hijack-vm-servers/)

## 🚨 À appliquer sans attendre

1. **Windows** : déployer les cumulatifs de novembre 2026 (KB5132061 / KB5131087 sur Windows 11, KB5131096 sur Windows 10 ESU) — le zero-day Outlook est exploité.
2. **Xen Orchestra** : mettre à jour immédiatement tout XCP-ng / Xen Orchestra exposé ; la faille de contournement d'authentification donne les droits admin.
3. **Git** : passer en 2.56.1 avant tout clone récursif de dépôt non maîtrisé, y compris dans les pipelines CI.
4. **SAP** : appliquer les correctifs de novembre, notamment ICM2SHELL et PROXYGATE (sévérité maximale) sur NetWeaver, Web Dispatcher et Gateway.
5. **Cisco BroadWorks / Openwave** : vérifier l'application des correctifs déjà publiés — exploitation active confirmée par la CISA.
6. **iOS** : éviter d'installer des applications non vérifiées sur iOS 26/27 tant qu'Apple n'a pas corrigé l'évasion de sandbox.
